# Session 0N – Title

Front matter, then these sections in this order. Section names are fixed so that every session
document reads the same way and the reviewer can compare sessions side by side.

::: ko
머리말(front matter) 다음에 아래 절을 이 순서대로 둔다. 절 이름은 고정이어서 모든 회기 문서가
같은 모양으로 읽히고, 검토자가 회기끼리 나란히 비교할 수 있다.
:::

## 1. Instructions

The language rule and the two or three sentences that frame the document as a session prompt.

::: ko
언어 규칙과, 이 문서가 회기 프롬프트임을 밝히는 두세 문장.
:::

## 2. Context and Purpose

Where this session sits in the treatment, what the previous session covered, what this one has to
achieve, and what is deliberately left for later sessions. Sources: book chapter and pages, the
recorded session, the current implementation.

::: ko
이 회기가 치료 전체에서 어디에 있는지, 직전 회기가 다룬 것, 이번 회기가 이루어야 할 것, 뒤 회기로
일부러 남겨 두는 것. 근거: 원서 장·쪽, 녹화된 회기, 현재 구현.
::: 

## 3. Your Role

What the assistant is in this session and how it works: Socratic, collaborative, one step at a time.
The persona itself is in the common document; this section says only what is specific to the session.

::: ko
이번 회기에서 도우미가 무엇이며 어떻게 일하는지: 소크라테스식, 협력적, 한 번에 한 단계.
페르소나 자체는 공통 문서에 있고, 여기에는 회기에 특유한 것만 적는다.
:::

## 4. Session Protocol — Step by Step

One subsection per step, numbered. Each step has the same five parts:

- **Purpose** — what the step obtains from the participant, in one sentence.
- **How** — the order of questions, what to offer only when the participant is stuck, what never to do.
- **Example wording** — one or two example questions, in quotes. Shape, not script.
- **Complete when** — the condition that ends the step; the next step starts only then.
- **Recorded** — what goes on the worksheet at this step, in plain words (no field names).

::: ko
단계마다 소절 하나, 번호를 붙인다. 각 단계는 같은 다섯 부분으로 쓴다.

- **목적** — 이 단계가 참가자에게서 얻는 것, 한 문장.
- **진행** — 질문 순서, 참가자가 막혔을 때만 내놓는 것, 절대 하지 않는 것.
- **예시 문구** — 예시 질문 한두 개, 따옴표 안에. 대본이 아니라 모양.
- **완료 조건** — 단계를 끝내는 조건. 다음 단계는 그때만 시작한다.
- **기록** — 이 단계에서 워크시트에 적히는 것, 쉬운 말로(필드 이름 없이).
:::

## 5. Restrictions — Critical Rules

Numbered. Only rules that are specific to this session; the rules every session shares are in the
common document.

::: ko
번호 목록. 이 회기에 특유한 규칙만. 모든 회기가 공유하는 규칙은 공통 문서에 있다.
:::

## 6. Tone and Style

Short. What a good turn sounds like in this session, and the two or three habits to avoid.

::: ko
짧게. 이 회기에서 좋은 턴이 어떻게 들리는지, 피해야 할 습관 두세 가지.
:::

## 7. Reference

Material the assistant reads from: the fixed scene, the list of the fifteen cognitive distortions,
the CD-Quest grid. Lists, not tables.

::: ko
도우미가 참고하는 자료: 고정 장면, 인지 왜곡 15가지 목록, CD-Quest 격자. 표가 아니라 목록으로.
:::

## Notes for review

Not part of the prompt. What this document leaves out or changes relative to the book, and why,
so that the reviewer can decide.

::: ko
프롬프트에 포함되지 않는다. 이 문서가 원서와 달리 빼거나 바꾼 것과 그 이유. 검토자가 판단할 수 있게.
:::
